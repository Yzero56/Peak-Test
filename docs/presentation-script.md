# PEAK SMART 발표 대본

권장 발표 시간: 광고 30초 + 제품 발표 7분

## 팀 활동 반영

- **YJ / Part 1**: ESP32-S3 Sense와 리드스위치로 냉장고 문 세션을 만들고, 손이 빠진 전후 프레임으로 IN / OUT / hand_only를 판정했습니다. held-out 74장 기준 정확도는 73.0%이며 낮은 확신도는 애매함으로 표시합니다.
- **Wa**: ESP32-S3 카메라, YOLO-World, DINOv2 임베딩과 분류기로 텀블러·반찬 용기·생수병을 구분합니다.
- **HJ**: Expo 앱에 식품 D-day, 온습도·가스 상태, 알림과 추천 레시피를 연결했습니다.
- **kang / Part 3·4**: FastAPI·PostgreSQL 기반 식품 API와 감지 이벤트를 구현하고, 용기 재식별 및 냉장고 자동 입출고를 연결했습니다.

발표에서 `CONCEPT`는 전체 제품 경험, `ACTUAL DEMO`는 현재 저장소에서 시연 가능한 기능으로 구분해 말합니다.

## 1. 표지 | 냉장고가 기억하는 유통기한

안녕하세요. 저희가 제안하는 서비스는 PEAK SMART입니다.

PEAK SMART의 출발점은 아주 단순한 질문입니다. 냉장고 안의 음식들은 지금 언제까지 안전할까요? 저희는 사진 한 장으로 식품 정보를 기록하고, 사용자가 오늘 무엇을 먼저 먹어야 하는지 알 수 있는 경험을 만들고자 했습니다.

## 2. 문제 | 우리는 매일 잊는다

우리는 식품을 사는 순간에는 날짜를 봅니다. 하지만 며칠이 지나면 언제 샀는지, 개봉했는지, 언제까지 먹어야 하는지 잊어버립니다.

기존 방식의 문제는 정보가 없다는 것이 아닙니다. 사용자가 매번 직접 입력해야 해서 기록이 지속되지 않는다는 점입니다. 결국 음식은 냉장고 안에 남고, 정보는 우리의 기억에서 사라집니다.

## 3. 약속 | 찍고, 확인하고, 안심하고 먹는다

PEAK SMART는 이 과정을 세 단계로 줄입니다.

먼저 식품 라벨을 촬영합니다. 다음으로 VLM이 이미지에서 식품명과 날짜를 읽어냅니다. 마지막으로 사용자는 분석 결과를 확인하고, 냉장고 목록에서 식품의 상태를 관리합니다.

핵심은 새로운 습관을 요구하지 않는 것입니다. 입력을 잘하는 사람이 아니라, 사진을 한 번 찍는 사람도 사용할 수 있어야 합니다.

## 4. 작동 방식 | 냉장고의 움직임이 오늘의 식단이 된다

실제 시스템은 센서와 카메라에서 시작합니다. 리드스위치가 냉장고 문 세션을 만들고, ESP32 카메라가 용기와 식재료를 봅니다. 문이 닫힌 뒤 손이 빠진 전후 프레임을 비교해 IN / OUT을 판정하고, 재식별 결과와 이벤트를 서버에 보냅니다.

백엔드에서는 이미지를 다섯 단계로 처리합니다.

이미지를 저장하고, 분석 작업을 큐에 넣습니다. VLM은 식품명, 제조일, 표시 유통기한, 보관 방법을 구조화된 데이터로 반환합니다.

서버는 날짜 형식을 하나로 정규화하고, 유통기한과 현재 날짜를 비교해 신선함, 임박, 만료 상태를 계산합니다. 이렇게 이미지가 실제로 행동할 수 있는 냉장고 데이터가 됩니다.

## 5. 경험 | 오늘 먼저 먹을 것은?

사용자에게 중요한 것은 복잡한 날짜 계산이 아닙니다. 오늘 먼저 먹어야 하는 음식이 무엇인지입니다.

그래서 PEAK SMART는 데이터를 세 가지 생활 언어로 바꾸고, HJ가 연결한 앱에서는 D-day·센서 상태·추천 레시피를 함께 보여줍니다. 기술의 결과가 숫자에 머무르지 않고 저녁 식탁의 선택으로 이어지는 구조입니다.

## 6. 신뢰 | 모르면 추측하지 않는다

식품 관리에서 가장 중요한 것은 그럴듯한 답이 아니라 믿을 수 있는 답입니다.

라벨 날짜를 읽지 못했을 때 AI가 임의로 날짜를 만들어내면 오히려 위험할 수 있습니다. PEAK SMART는 읽지 못한 값을 null로 남기고, 신뢰도가 낮거나 검토가 필요한 경우 needs_review로 표시합니다.

즉, AI가 모든 것을 자동으로 결정하는 것이 아니라 사용자가 마지막으로 확인할 수 있게 설계했습니다. 정확성뿐 아니라 불확실성까지 기록하는 것이 저희의 신뢰 설계입니다.

## 7. 현재와 다음 | 설계에서 작동하는 백엔드로

현재 FastAPI 기반 프로젝트 구조와 PostgreSQL을 고려한 데이터 모델을 만들었습니다. 식품 CRUD API, 이미지 업로드와 저장, 유통기한 상태 계산, Mock VLM과 OpenAI 호환 VLM adapter까지 구현했습니다.

다음 단계는 실제 VLM 호출 테스트, 대시보드 요약 API, 그리고 프론트엔드와의 전체 흐름 검증입니다. 이미지 업로드부터 분석 결과 확인, 식품 등록, 대시보드 조회까지의 MVP 흐름을 완성하는 것이 목표입니다.

## 8. 마무리

PEAK SMART는 냉장고를 단순히 더 똑똑하게 만드는 기술이 아닙니다. 우리가 음식을 더 잘 기억하고, 더 잘 소비하고, 덜 버리게 만드는 경험입니다.

버리는 음식은 줄이고, 먹는 순간은 늘리는 것. 이것이 PEAK SMART가 만들고 싶은 변화입니다. 감사합니다.
