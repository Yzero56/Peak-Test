# Part 1 — 냉장고 IN/OUT 판정

XIAO ESP32-S3 Sense + OV3660 카메라와 리드스위치로 냉장고 문 개폐를 감지하고,
문이 열려있는 동안 손 위치를 추적해 "무언가 들어갔는지(IN) / 나갔는지(OUT) /
아무 일도 없었는지(hand_only)"를 판정하는 실시간 시스템.

## 핵심 설계

- **손 위치 기반 동적 크롭**: MediaPipe HandLandmarker로 손이 처음 보인 위치를
  기준으로 크롭 영역(ref_box)을 잡는다 — 냉장고 전체가 아니라 실제 손이 닿은
  선반만 비교해서 신호 대 잡음비를 높인다.
- **hand-free before/after**: 손이 화면에 보이는 채로 찍으면 "손에 뭘 들고
  있나"가 방향(IN/OUT) 신호를 가려버려서, 손을 뺀 상태로 전/후 두 장을 찍는
  방식으로 전환했다.
- **diff 인코딩**: 전/후 두 장을 좌우로 이어붙이는 대신, 픽셀 단위 밝기
  변화량을 색으로 인코딩한 한 장짜리 이미지로 변환해서 학습에 사용한다
  (R=밝아짐/생김 후보, B=어두워짐/없어짐 후보). 좌우 이어붙이기 방식은
  CNN이 "비교"라는 개념 자체를 학습하지 못하는 문제가 있었다(순서를 바꿔도
  예측이 안 바뀜 — swap 테스트로 확인).
- **Edge Impulse 전이학습(MobileNetV2, 96x96) + 로컬 TFLite 추론**: 카메라가
  자체 Wi-Fi 핫스팟(AP 모드)이라 인터넷이 없는 환경에서도 동작하도록 클라우드
  분류 대신 로컬 모델(.eim)로 판정한다.
- **낮은 확신도는 "애매함"으로 표시**: 정확도가 아직 완벽하지 않아서, 확신이
  낮은 판정을 확정적으로 틀리게 보여주는 대신 정직하게 "판단 애매함"으로
  표시하는 임계값(confidence < 0.5)을 뒀다.

## 결과 (held-out 테스트 88장 기준, 현재 배포 모델)

**정확도: 76.1%** (baseline 33.3%, 3-class 무작위 대비 +42.8%p)

| 클래스 | 재현율 |
|---|---|
| hand_only | 100% (9/9) |
| in | 66.7% (26/39) |
| out | 80.0% (32/40) |

원래 학습에 쓰지 않은 다른 냉장고에서 찍은 사진만 따로 뽑아도 81.8%(9/11) —
처음 보는 환경에서도 어느 정도 일반화됨을 확인.

Confusion matrix: `confusion_matrix.png` 참고. 라운드별 전체 기록(정확도 추이 +
라운드마다의 confusion matrix)은 `Part1_Accuracy_History.pdf` 참고.

## 알려진 한계

- 학습 데이터가 아직 작음(~440장/3클래스) — **데이터를 큰 단위로(수십 장 이상)
  늘릴 때는 항상 정확도가 개선됨**(143장 59% → 202장 61.7% → 381장 73.0% →
  442장(다른 냉장고 데이터 병합) 76.1%).
- 반면 **실전 오답을 10~15건 단위로 소량 보정해 바로 재학습하는 방식은 두 번
  다 오히려 정확도가 하락**했음(전체 데이터의 몇 %도 안 되는 소량 추가는
  재학습 시의 랜덤 노이즈에 묻힘) — 데이터를 추가할 땐 큰 단위로 모아서
  넣는 게 효율적임을 확인.
- 방향(순서) 민감도가 아직 불완전함 — swap 테스트 결과 약 절반의 샘플만
  순서를 바꾸면 예측이 뒤집힘(완전한 순서 학습은 아직 안 됨).
- 문을 빠르게 연속으로 여닫으면 세션이 뒤섞이는 경향이 있어 최소 세션
  길이 가드(1.2초)를 추가함.
- 처음 보는(학습에 안 쓰인) 냉장고에서는 조명/선반 색이 다르면 정확도가
  떨어질 수 있음 — 새 환경마다 소량이라도 데이터를 추가하는 게 도움이 됨.
